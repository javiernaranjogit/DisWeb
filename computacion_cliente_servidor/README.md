# Computación cliente-servidor

Prácticas de la asignatura: formularios web con validación en cliente y en servidor, y un panel
de administración con persistencia en MySQL.

**Tecnologías**: PHP · MySQL · JavaScript · CSS

## Contenido

- `actividad_1/` — formulario y página de confirmación en PHP puro.
- `actividad_2/` — se añade validación en cliente con JavaScript.
- `actividad_3/` — versión final, con validación en ambos lados.
- `dashboard.php` y ficheros de la raíz — panel de administración de los envíos.

## Ejecutar

Necesita un servidor con PHP y MySQL (XAMPP, MAMP o similar). Copia la carpeta en el directorio
raíz del servidor web e importa el esquema de base de datos correspondiente.
