# Experiencia de usuario

Prototipo web centrado en usabilidad y diseño de la interfaz: maquetación responsive, jerarquía
visual y navegación.

**Tecnologías**: HTML5 · CSS3 (con `normalize.css`)

## Contenido

- `index.html` — página principal.
- `reparto.html` — fichas del reparto.
- `ubicacion.html` — localización con mapa.
- `resources/` — hojas de estilo e imágenes.

## Ejecutar

Sitio estático: basta con abrir `index.html` en el navegador.
