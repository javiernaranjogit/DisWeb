# Lenguajes, estándares y tecnologías web

Práctica sobre estándares web: modelado de datos en XML con su gramática, y un sitio HTML5 que
consume esa información e incorpora contenido multimedia accesible.

**Tecnologías**: XML · DTD · XSD · HTML5 · CSS3

## Contenido

- `actores.xml` con su gramática en `actores.dtd` y `actores.xsd` — modelado y validación.
- `index.html`, `reparto.html`, `contacto.html`, `dashboard.html` — páginas del sitio.
- `cast/` — ficha individual de cada actor.
- `resources/` — estilos, imágenes y audio.

## Ejecutar

Sitio estático: abrir `index.html` en el navegador. Los XML se validan contra su DTD/XSD con
cualquier validador (`xmllint --valid`, por ejemplo).
